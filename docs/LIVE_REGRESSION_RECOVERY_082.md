# Deep Sims 0.8.2 live-regression recovery

The retained Identity Editor now owns the top/stretch geometry of every layout block, resets the
scroll position after rebuilding content, reserves the verified header area, and renders above the
retained Suite navigation. This keeps the first visible field (Background) usable at supported
resolutions without changing memory ownership or persistence behavior.

For MMO-perspective out-of-character player-identity questions, the compact direct prompt now
explicitly routes the answer to the simulated-player background and forbids answering from current
Erenshor character state. Roleplay isolation remains unchanged.

Live QA: open the editor immediately after launch, switch Sims, edit and reset Background/Pronouns,
and ask an MMO IRL-style question that could otherwise be answered from class/build/zone state.
